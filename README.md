# 🥕 Roll-A-Carrot

A colorful, low-poly island adventure featuring a carrot, collectible coins, and themed worlds.

Created by **Miguel Bobadilla** for **NJIT IT201-007 — Information Design Techniques, Fall 2026**.

## 🎮 About the Game

Roll-A-Carrot takes inspiration from playful platform adventures. Explore grass, desert, snow, castle, and sky areas, collect coins to unlock routes, and avoid enemies along the way.

## ✅ Current Features

- Carrot player with animated idle and running states
- Smooth character turning
- Collectible coins and an on-screen counter
- Doors that unlock as you collect coins
- Multiple themed areas
- Enemy encounters and a following pet

The project is still in development as I complete the course assignments.
